# 交互教程

[English](tutorial.md) | **简体中文**

[文档目录](README.zh-CN.md) / [入门指南](getting-started.zh-CN.md)

空白世界会显示 OAW 标志和三个选项：**Start Tutorial（开始教程）**、**Place Minister Card（放置 Minister 卡牌）**、**Start Directly（直接开始）**。教程在真实画布上进行，涵盖画布导航、卡牌、Agent—Conversation—Sandbox 工作流程、卡牌粘合和 Minister。世界控制区的指南针按钮可以重放教程。

向导会等待你完成操作。它的小指南针按钮可定位当前目标，或恢复缺失的卡牌。将气泡最小化可以腾出空间；点击 × 可跳过教程。重新加载后，可以选择继续或重新开始。模型配置使用普通的 Agent 设置和 **Manage models（管理模型）**。向模型发送消息是可选步骤；要获得有用的回复，需要配置真实的模型服务。向导不会生成模拟回复，也不会替你启动沙盒。

## 准备牌组

向导会依次指向卡牌库、入门卡包和打开后的包装。将 Text、Agent、Conversation 和 Sandbox 拖入收藏侧栏中选定的同一个牌组，然后激活该牌组返回画布。点击 **Add to（添加到）** 也会打开同样的目标选择界面。所选牌组必须包含这四种可用卡牌，才能继续。

## 完成、跳过与恢复

你放置的卡牌和收集到牌组中的条目会保留在世界里。向导会登记临时 Text 卡牌，并在完成、跳过或重新开始时移除未经修改的演示道具。如果你编辑了道具、为它建立连线，或将它粘到自己的卡牌上，它会被保留。清理失败时会保留登记记录，并提供重试入口。

## 实现说明

- `frontend/src/onboarding/steps.ts` 定义章节顺序和纯完成条件。每一步都有稳定 ID、简短对话、目标、可选演示，以及预期操作或手动继续。新增章节应在这里添加，并明确实现新的条件或操作；当前没有工作流语言或插件 SDK。
- `controller.ts` 负责进度、API 编排、恢复和临时卡牌登记，订阅 `worldStore`、`nodeSurfaces` 和 `cardLibrary`。`oaw-onboarding-v1` 仅持久化公开 ID、内容修订版本、名称和进度，不保存消息内容、模型凭据或世界副本。持久化按浏览器来源划分，与当前单世界前端一致。未来若加入工作空间切换器，应为该记录绑定权威的世界标识。
- `state/interactions.ts` 在状态快照无法识别操作者时记录成功的 UI 信号，包括用户视口变化、聚焦、已确认发送的消息、Minister 在场状态和成功保存的粘合关系。这些信号由普通交互处理器发出。卡牌手势和图权限没有教程专用实现；发送失败或仅完成乐观更新的粘合操作不能使步骤完成。
- `Onboarding.tsx` 将向导放在当前目标旁边，突出显示目标，并提供可取消的视觉演示。`placement.ts` 让气泡避开控件，并为道具和 Minister 寻找空位，不移动已有卡牌。真实卡牌放置、位置提交、关系和粘合仍使用现有卡牌库、世界及共享粘合 API。正常的能力选择、删除与撤销、Minister 确认保持原有行为。
- 放置卡牌时，会在首次绘制和相机取景前将真实节点暂存。一个不可交互的副本在屏幕坐标中飞入，真实节点、向导锚点和聚光区域则保持最终边界；完成后，在下一次绘制前显示真实节点并移除副本。取消时始终清除暂存状态。卡牌库提示在模态框内部渲染，以便在浏览器顶层中保持可交互。
- `OawGuide.tsx` 在欢迎姿态中完整保留已采用的 `docs/assets/logo.svg`。入场时，单个圆形头部从侧面标志的位置移动到站立角色的位置，同时身体变为对称的正面轮廓。站立比例和动作参考来自 `.tmp` 中的素材，保留标志的圆头、藏青色、渐收身体和双腿，不添加手臂或额外身体结构。
- `guideRig.ts` 使用矢量骨骼实现站立角色。每条腿包含髋、膝、足链，由双骨骼逆向运动学（IK）求解；带权重的三次曲线边界控制点将轮廓绑定到骨盆、大腿和小腿。Idle、Walk、Jump、Think、Indicate、Speak 和 Enter 共用同一骨架。意图状态机在切换时保留姿态和速度，单次跳跃结束后返回最新意图。宿主测得的屏幕移动驱动步速和方向，教程操作成功时触发跳跃。减少动态效果模式保持中性站姿。单个动画时钟直接更新 SVG 几何形状，不逐帧触发 React 渲染，也不重启 CSS 动画。`debug` 可在开发预览中显示骨骼。

是否进入教程取决于完整的权威世界快照，因此已有内容的世界不会仅因当前视口为空而触发新手引导。清理已登记道具前，会取消尚未结束的演示并等待其收尾。重新加载会暂停教程，不会在后台继续修改世界。恢复逻辑不会将卡牌不在视口内视为成功删除；删除必须有现有历史记录或运行时删除证据。

## 验证

在 `frontend` 目录运行：

```sh
npx vitest run src/onboarding src/state/interactions.test.ts
node scripts/run-e2e.mjs e2e/onboarding.spec.ts e2e/guide-rig.spec.ts
```

浏览器测试覆盖欢迎选项、小视口、重新加载与继续，以及正常和减少动态效果模式下的完整教程。测试使用现有隔离后端，执行真实手势、授予真实关系，并检查清理道具后工作流程仍然有效。隔离后端使用测试运行时；这些测试不能证明真实模型的回复质量或原生沙盒执行有效。
